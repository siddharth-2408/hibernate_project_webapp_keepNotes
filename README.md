/*Keep Notes Project using Hibernate ORM in Java*/

Steps for the project creation so that I can remember it easily
1. New Maven Project In Eclipse
2. Now under resources folder, create a hibernate.cf.xml file with the default schema from Internet and add 2 dependencies a. hibernate-core b. mysql(your own version)
3. Now create the frontend with different pages, style it with your knowledge or any templates available
4. Now under java folder, create a class in a package which will contain the Entity i.e of which the table is to be created in the database
5. Define the variables and initialise constructors
6. Create another package which will contain a helper class which will provide us with SessionFactory's reference in order to create sessions;
7. Create different servlets like Add,Delete,Update for different dB operations.
8. Run them on Apache Tomcat Server.
9. Voila! Project Created;
Base Time showed in Tutorial:- 2 hours;
Time Taken to be Completed with basic functionalities:- 2 business days.
